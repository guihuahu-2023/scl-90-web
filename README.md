# 🌸 SCL-90 心理自查 · 温柔版

> 基于 SCL-90（症状自评量表）的心理自查小工具，90 道题，约 15–25 分钟。
> 设计 & 整理：那年的雪糕

## 它是什么

一份用于**自我了解**的量表工具，覆盖 10 个维度、共 90 道题：

| 维度 | 题目数 | 关注内容 |
|---|---|---|
| 躯体化 | 12 | 身体各部位的不适感 |
| 强迫症状 | 10 | 反复检查、控制不住的想法与行为 |
| 人际敏感 | 9 | 对他人的态度、评价是否敏感 |
| 抑郁 | 13 | 情绪低落、兴趣减退、绝望感 |
| 焦虑 | 10 | 担忧、紧张、惊恐 |
| 敌对 | 6 | 生气、冲动、摔打 |
| 恐怖 | 7 | 对特定场所/情境的害怕 |
| 偏执 | 6 | 猜疑、神经过敏 |
| 精神病性 | 10 | 孤独、幻听、思维被控制等 |
| 其他 | 7 | 睡眠、饮食等 |

## 怎么测

1. 打开 `index.html`（双击即可，无需安装、无需联网，结果不会上传到任何服务器）
2. 点「开始测试」，按**最近一周**的实际感受，每题选 0–4 分：
   `0 没有 ｜ 1 轻微 ｜ 2 中度 ｜ 3 偏重 ｜ 4 严重`
3. 进度自动保存在本机，中途可关掉，下次点「继续上次作答」
4. 答完点「查看结果」

## 结果怎么看

**核心四项指标（参考线）**

| 指标 | 参考线 |
|---|---|
| 总分 | < 160 |
| 总均分 | < 2 |
| 阳性项目数（得分 ≥1 的题数） | < 43 |
| 阳性症状均分 | > 2 需留意 |

**10 个维度**：每项得分会对照中国正常人群常模（X 与 X+SD），标出三档——
🟢 正常 ｜ 🟡 略偏高 ｜ 🔴 需关注，并列出困扰最明显的具体题号，方便回溯。

## 功能

- 💾 自动保存进度，可中断、续答
- 📥 一键下载独立报告（HTML）/ 🖨️ 打印或另存为 PDF
- ↻ 重新测试

## 重要说明

- 本结果依据 SCL-90 标准计分法（0–4 五级）与正常人群常模生成，**仅用于自我觉察，不是医疗诊断**
- 若「想结束自己的生命」等相关题目得分不为 0，或有持续情绪低落，请认真求助：联系家人朋友、学校/单位心理中心，或就近医院心理科；需要即时支持可拨打当地 24 小时心理援助热线
- 结果只保存在你本人的浏览器里，仅自己可见

## 怎么分享给别人

- **直接发文件**：把 `index.html` 通过微信/网盘发给对方，保存后双击打开即可
- **托管出链接**：把本仓库的文件传到 GitHub Pages（免费），得到一个谁都能打开的网址
